# Creative Memories Studio — Website Starter

This ZIP contains the connected frontend foundation:
- index.html
- style.css
- script.js
- data/portfolio.js
- data/services.js
- assets folder
- pages folder placeholder

IMPORTANT:
1. Put your original Creative Memories Studio PNG logo at:
   assets/logo.png
2. Sample visual files are referenced in data/portfolio.js:
   wedding.jpg, portrait.jpg, commercial.jpg, events.jpg, travel.jpg, drone.jpg
   Replace these with your real/AI-generated images.
3. This frontend is intentionally structured for later backend/API integration.
4. Secure authentication, payment processing, private cloud gallery, WhatsApp API, invoices, CRM and AI services require a backend/provider configuration and must not be implemented with client-side secrets.
5. Google Fonts are loaded from the web in style.css. For fully offline use, download/licence the required fonts and update the CSS.

Suggested next production phases:
Frontend -> Backend/API -> Database -> Auth -> Booking -> Payment -> Storage/Gallery -> WhatsApp/Email -> CRM -> AI services -> Android app -> Security/testing -> Deployment.
